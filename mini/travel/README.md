# travel

Личная страница «Мои путешествия» — интерактивная карта посещённых регионов России, Таиланда и Грузии. Single-user, без БД.

## Маршрут на продакшене

https://nice-guy-ai.vercel.app/travel

## Сценарий

1. Открыть `/travel` — landing с двумя кнопками-карточками.
2. Кликнуть «HTML-версия» → откроется `/travel/map.html` (Leaflet, регионы, города, переключение стран).
3. Кликнуть «SVG-версия» → откроется `/travel/map.svg` (статичная векторная карта).

## Файлы карт

- `public/travel/map.html` — основная Leaflet-карта (источник — присланный заказчиком файл).
- `public/travel/map.svg` — альтернативная SVG-карта (заказчик присылает отдельно).

## Локальный запуск

```bash
npm run dev
# открыть http://localhost:3000/travel
```
