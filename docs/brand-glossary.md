# Словарь бренда платформы

Источник истины для канонических фраз. Скиллс `book-to-modes`, инструкция `docs/runbooks/add-new-book.md` и автопроверка `npm run check` сверяются с этим документом.

## Каноническая лексика

| Контекст | Каноническая фраза | Где |
|---|---|---|
| Название платформы / бренд | **Книжный Спарринг** | Только в трёх местах: шапка сайта, подвал сайта, ярлык карточки сравнения форматов. |
| Описание формата программы | **Онлайн-тренажёр по книге [Название]** | Тег над заголовком (hero_tag), подзаголовок героя, мета-теги, описания в каталоге, FAQ. |
| Главный субъект чата с пользователем | **Система** | Везде, где раньше были «ИИ», «ИИ-ассистент», «ИИ-тренер», «ИИ-коуч», «ИИ-стратег» и подобные роли. Просто «Система», без дефисов и дополнительных существительных. |
| Тип категории на верхнем уровне | **Онлайн-тренажёры по книгам** | Title главной, общие меты, описания каталога. |

## Запрещено в коде

Линтер `npm run check` падает, если находит эти фразы в seed-SQL и видимых компонентах фронтенда:

| Фраза | Что вместо |
|---|---|
| `AI-тренажёр` / `Книжный Спарринг по книге X` / `Книжный Спарринг — мост` (описания формата) | `Онлайн-тренажёр по книге X` |
| `ИИ-ассистент`, `ИИ-тренер`, `ИИ-коуч`, `ИИ-стратег`, `ИИ-редактор`, `ИИ-помощник`, `ИИ-автор`, `ИИ-аналитик`, `ИИ-консультант`, `ИИ-наставник`, `ИИ-Тревис` и любой `ИИ-<существительное>` | `Система` |
| `AI-ассистент`, `AI-тренер`, `AI-<любое>` (с латиницей) | `Система` |
| `ИИ` как отдельное слово в видимом тексте («ИИ помнит», «общение с ИИ», «через ИИ») | `Система` |
| `AI` как отдельное слово в видимом тексте | `Система` |
| `Nice Guy AI` (старое название платформы) | `Книжный Спарринг` (только в шапке/подвале) или `Онлайн-тренажёр по книге X` (в текстах) |
| `Ежедневная практика` в `landing_data.comparison.columns[*].role` | `Практика` |

## Где «Книжный Спарринг» ЕДИНСТВЕННО допустим

- Верхний бар сайта (компонент шапки) — название платформы.
- Подвал сайта (`© 2026 Книжный Спарринг`).
- Ярлык карточки сравнения форматов (`landing_data.comparison.columns[*].name` для нашей колонки).
- Юридический документ оферты — один раз как формальное имя платформы (`«Книжный Спарринг»`).

## Где «AI» / «ИИ» допустимы

- В служебных комментариях кода (`// Stream with Vercel AI SDK`, `/* AI block insight */`) — техническая разметка, пользователь не видит.
- В именах npm-пакетов и SDK (`@vercel/ai-sdk`, «Vercel AI Gateway») — это бренды сторонних библиотек.
- В именах файлов компонентов (`AIMessage.tsx`) — внутренние идентификаторы.
- В словах «искусственный интеллект» полностью (например в legal — «использует искусственный интеллект»).

## Грамматические подсказки для слова «Система»

Слово «Система» — женский род, склоняемое:

| Падеж | Форма | Пример |
|---|---|---|
| Именительный | Система | «Система помнит ваш портрет» |
| Родительный | Системы | «рекомендации Системы» |
| Дательный | Системе | «доступ Системе» |
| Винительный | Систему | «через Систему» |
| Творительный | Системой | «общение с Системой», «чат с Системой» |
| Предложный | Системе | «о Системе» |

После замены «ИИ» → «Система» проверь согласование соседних слов («каждый» → «каждая», «он» → «она»).

## Что делать при изменении этого словаря

Если ты переименовываешь сквозную фразу платформы:

1. **Обнови этот файл** — добавь старую фразу в «Запрещено в коде», новую в «Каноническая лексика».
2. **Обнови скиллс** `[.claude/skills/book-to-modes/SKILL.md](../.claude/skills/book-to-modes/SKILL.md)` и `[.claude/skills/book-to-modes/references/PLATFORM_MAP.md](../.claude/skills/book-to-modes/references/PLATFORM_MAP.md)` — все шаблоны JSON и описания полей.
3. **Обнови инструкцию** `[docs/runbooks/add-new-book.md](runbooks/add-new-book.md)` — примеры JSON и комментарии.
4. **Обнови seed-файлы программ** `scripts/seed-*.sql` — чтобы при пересоздании БД с нуля сразу стояло правильно.
5. **Обнови БД через `jsonb_set` или `regexp_replace`** (НЕ через полную перезапись `landing_data`). Шаблон — `scripts/fix-comparison-brand.sql`.
6. **Расширь автопроверку** `scripts/check-hardcodes.sh` — добавь новую запрещённую фразу.
7. **Прогони `npm run check`** — должно пройти зелёным.

## Связь с правилами

- В `CLAUDE.md` есть правило про сквозные тексты — оно обязывает свериться с этим документом при каждом сквозном переименовании.
- При добавлении новой функции, попадающей в шаблон книги (новое поле в `landing_data`, новая колонка в `programs`) — обновить и этот словарь, и скиллс.
