# AUTHOR_NAMES — справочник транслитерации имён авторов

Канонические русские написания имён авторов всех уже добавленных книг. При добавлении новой книги: имя автора — отсюда, а не «как первое в голову пришло».

## Зачем

После Пристли всплыло: имена авторов в БД могут случайно остаться на английском (`Daniel Priestley & Glen Carlson` в `author.name`, «Daniel — автор бестселлера» в `credentials`, «Спросить Daniel Priestley» в label кнопки author_chat). Также при разных правках разные кирпичи получают разную транслитерацию (`Дэниел` / `Дэниэл` / `Даниэль`). Справочник убирает оба источника ошибок.

## Правило

1. **Все user-facing поля** (`landing_data.author.name`, `author.credentials`, `welcome_*`, `mode_templates.name` через `welcome_mode_label`, label кнопки author_chat в seed-modes) — **на русском по этому справочнику**.
2. **Поле `landing_data.book.author_top`** — на языке оригинала книги (`Daniel Priestley with Glen Carlson`), это библиографическая запись «как на обложке».
3. **Исключение** — профильная клиническая книга для специалистов (`transdiagnostic-cbt`). Имя автора оставлено на английском намеренно, ЦА узнаёт по оригинальному написанию.

## Как пользоваться при новой книге

1. Перед seed — найди оригинальное написание имени автора (Wikipedia, обложка книги).
2. Если у автора есть **переведённая** на русский книга — бери русское написание имени с обложки русского издания (это уже канон для русскоязычной аудитории).
3. Если книги на русском нет — транслитерируй сам по правилам ниже (раздел «Принципы транслитерации»). И добавь в реестр выше.
4. Если **несколько авторов** — иди по таблице «Несколько авторов и фото» в [`PLATFORM_MAP.md`](PLATFORM_MAP.md): один на фото → `author.name` = главный, второй упомянут в `credentials`.
5. Имя в `author.name` повторяется в `mode_templates.name` (через `welcome_mode_label` для author_chat) — должно совпадать буква в букву. Не «Дэниел» в одном поле и «Дэниэл» в другом.

## Принципы транслитерации

- Используй **самое распространённое** русское написание (то что в Википедии в названии статьи об авторе).
- Daniel → **Дэниел** (не Даниэль, не Дэниэл). Brad, Bradberry → **Бред**, **Бредберри**.
- Двойные согласные сохраняем: Gottman → **Готтман**, Bradberry → **Бредберри**.
- Окончания `-son`, `-ton` → **-сон**, **-тон**: Carlson → **Карлсон**, Newton → **Ньютон**.
- Стивен/Стефан: Stephen → **Стивен** (англ.), Stephan → **Стефан** (нем.).
- Артикли и средние инициалы оставляем: John M. Gottman → **Джон Готтман** (M. опускаем в `author.name` для краткости, но можно оставить если автор так подписывается).
- Учёные степени (PhD, MD) — оставляем латиницей: «Эдит Эва Эгер, PhD».

## Когда обновлять справочник

Каждый раз когда добавляется новая книга в БД — добавь строку в реестр выше **в том же commit**, что seed-файл программы. Иначе следующая книга снова будет «как первое в голову пришло».
