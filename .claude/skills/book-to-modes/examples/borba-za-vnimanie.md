# borba-za-vnimanie — ретроспектива

**Книга:** Максим Белоусов «Борьба за внимание» (АСТ 2021).
**Slug:** `borba-za-vnimanie`. **Тип:** маркетинг + прикладная психология (третья маркетинговая после Ильяхова и Марк/Пирсон).
**Features:** `free_chat`, `author_chat`, `portrait`, `modes`, `calibration` (без exercises и test).
**Режимы (5 кастомных + 2 shared):** `belousov_calibration` (free, «Сначала это»), `belousov_contexts` (paid, «Флагман» — 5-столбцовая методика автора), `belousov_lenses`, `belousov_equalizer`, `belousov_kdm`, `free_chat`, `author_chat`.

## Что сработало

- **Транскрипт авторского тренинга как источник тона.** Методика «Контексты» (5 столбцов) — не в книге, передана только на личных тренингах КЭС. Заказчик дал расшифровку → буквальные цитаты автора попали в промпты («Это не действие, это эфемерная хрень», «Чтобы тебя ночью разбудили — ты повторил»). Прямой стиль Белоусова получился узнаваемым, особенно у `author_chat`.
- **Стоицизм-фрейм как мост маркетинг↔психология.** Для книги, которая формально про маркетинг но методология — психологическая, фундамент «ты на 100% влияешь только на себя» дал единый тон во всех 5 режимах. Без этого было бы либо «коуч-штампы», либо «терапия» — выбрали третье.
- **Бейджи на хабе «Сначала это» (calibration) + «Флагман» (контексты).** Чёткая навигация для первой сессии: пройди настройку → переходи в флагман. Без бейджей хаб с 5 примерно равными по весу режимами выглядел бы перегруженно.
- **Дозированный мат у `author_chat`.** Белоусов в реальной речи использует «короче», «нахер» дозированно — попробовали оставить в промпте именно как «дозированно, не перебор». Получилось аутентично без перегиба. Шаблон годится для других маркетологов с резким стилем.
- **КДМ как отдельный режим (а не вложенный в Контексты).** Авторский «Комплексно-Дедуктивный метод чтения людей» из главы 6 книги — самостоятельный тренажёр с гипотезами и тактиками, не подбулет «диагностики Контекстов».

## Что пришлось изобретать

- **5-столбцовая таблица в системном промпте** (`belousov_contexts`). Это не reply-формат и не QR-блок — это явная UX-структура которую AI должен поддерживать на протяжении фаз 3-6 диалога. Решение: описать структуру в промпте + 3-4 примера из транскрипта тренинга («Артём: лишний вес → не создал комфорта», «Наташа: болеет мама → чувство долга») + явный шаблон финального блока с эмодзи-маркерами (`📍 Точка`, `🎯 Решение` и т.д.). Без таких примеров AI скатывался либо в коучинг, либо в «дай мне три действия».
- **Маркер `[КАЛИБРОВКА ЗАВЕРШЕНА]`** в финальном сообщении `belousov_calibration` — попытка протолкнуть факт прохождения калибровки в следующий режим через парсинг текста. **Не сработало** — никто его не парсит. Калибровка нашлась через стандартный `appendCalibrationContext()` (см. урок ниже про whitelist).

## Специфика книги

- **Маркетинговая по теме, психологическая по методу.** В отличие от Ильяхова и Марк/Пирсон у Белоусова главный инструмент (Контексты) не про тексты/архетипы, а про работу с пластом жизненных решений. Это значит — портрет, безопасность, эмпатия в режимах нужны как у психологических книг, не как у чисто маркетинговых.
- **Источник методики ≠ книга.** Главный режим основан на материале вне книги. Решение — описать методику в промпте подробно (5 столбцов + 8 типов неэресурсных контекстов + цитаты) и в `docs/books/borba-za-vnimanie.md`.
- **Тест опущен по запросу.** Кандидат «тест на тип неэресурсного контекста» оставлен в backlog (`docs/books/borba-za-vnimanie.md` → TODO).

## Уроки для шаблона book-to-modes

1. **Добавляешь режим с суффиксом `_calibration`** → обязательно дополни `CALIBRATION_CHAT_TYPES` в `lib/chat/prepare-context.ts`. Иначе калибровка декларативная. Линтер `npm run check:chats` ловит правилом `calibration-not-wired`.
2. **Не клади cover.jpg как фото автора**, даже если на обложке автор. Линтер `npm run check:author-photos` ловит md5-сравнением через правило `author-photo-equals-cover`.
3. **Удаляй `{{cross_mode_data}}` placeholder** из шаблонных промптов при копировании из других книг — он не подменяется в коде. Linтер `npm run check:chats` ловит правилом `cross-mode-data-placeholder`.
4. **Если методика автора живёт вне книги** (тренинг, курс, личные сессии) — фиксируй её как первоисточник в `docs/books/<slug>.md` отдельной секцией с цитатами. Промпт без них теряет узнаваемость автора.
