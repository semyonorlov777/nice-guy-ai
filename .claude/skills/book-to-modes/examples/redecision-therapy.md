# Конспект решений: Психотерапия нового решения (Гулдинги)

**Slug:** `redecision-therapy`
**Тест slug:** `redecision-test`
**Тип:** Терапия (классический метод TA + Gestalt)
**Объединение:** Нет — одна книга
**Дата:** 2026-05-14 (седьмая книга платформы; третий диагностический тест после ISSP/GPP)

## Книга

Мэри и Роберт Гулдинги. «Психотерапия нового решения. Теория и практика». Класс, 1997. Оригинал: Changing Lives Through Redecision Therapy (Brunner/Mazel, 1979). Ученики Эрика Берна.

Метод — синтез транзактного анализа Берна и гештальт-терапии Перлза + собственная техника «нового решения» (redecision).

## Ключевые решения

1. **Два автора в author_chat — голос «мы»** с редкими переходами к именам. Уникально для платформы (раньше все author_chat были от одного автора).
2. **5 шкал из 12 предписаний** — объединил «Не близким + Не доверяй» = intimacy, «Не будь собой + Не говори + Не думай» = authenticity. Ортогональные кластеры.
3. **«Не существуй» (суицидальное предписание) НЕ выделено отдельной шкалой** — суицидальные сигналы обрабатываются строгим redirect к специалисту (телефон доверия 8-800-2000-122), не через тест.
4. **Безопасность строго** — в каждом system_prompt вшит блок про кризис: при сигналах суицида / клин. депрессии / абьюза → AI выходит из роли, не имитирует терапию, не принимает антисуицидальный контракт. Прецеденты: notes_energy_architect, eq_self_management.
5. **Прогрессия Увидеть → Понять → Действовать** (как у Берна games-people-play) — проверенный паттерн для терапевтических книг.
6. **Префикс `rd_`** для всех ключей режимов и шкал.
7. **Связка с Берном** — одна фраза в Author-секции лендинга «Гулдинги — ученики Берна, развили его метод», без CTA на games-people-play.

## Что сработало

1. **Полный текст книги + один Explore-агент = быстрый Этап 1.** Никаких Deep Research, дисамбигуации авторов, проверки контаминации. Терапевтическая классика — авторы хорошо известны, нет однофамильцев.
2. **Безопасность как первоклассный концепт в промптах.** В каждом из 6 system_prompt + 3 programs-level + test_system_prompt вшита фраза про кризис и телефон доверия. Линтер пока не проверяет наличие safety-блока — это отдельная задача на скилл.
3. **Author chat от «мы»** работает. Прецедент создан — следующие книги с двумя авторами (если будут) могут использовать тот же паттерн.
4. **Локальная папка `/books/`** для обложек книг, которых нет на cdn.litres.ru. Раньше для 100-notes был labirint URL в CSP — теперь можно скачивать локально и не править CSP.
5. **0 fix-*.sql после первого seed** — линтер прошёл сразу. Это второй проект подряд (после eq-2-0), где удалось избежать типичной серии правок.

## Что пришлось изобретать на ходу

1. **Голос пары авторов** — раньше все author_chat имитировали одного человека. Решил через множественное «мы» + редкие переходы к именам. Не сложно, но новый паттерн.
2. **Папка `public/books/`** — раньше обложки только из cdn.litres.ru. Создал директорию, добавил `/books/<slug>.png` в landing_data.book.cover_url. Работает через `'self'` CSP, не нужны изменения в next.config.ts.
3. **Терапевтическая безопасность интенсивнее** чем в других книгах — Гулдинги много пишут про суицид, абьюз, депрессию. В каждый промпт пришлось добавить явный safety-блок с redirect к специалисту. Это шаблон для будущих терапевтических книг.

## Что заняло больше всего времени

1. Чтение книги Explore-агентом и составление развёрнутой сводки (~5 мин)
2. Написание 6 system_prompts для режимов через MCP (по ~3-4 KB каждый) — самая трудоёмкая часть (~25 мин)
3. interpretation_prompt теста с авторской терминологией и связкой с режимами (~5 мин)
4. Лендинг (landing_data JSON со всеми секциями) — ~10 мин
5. Поиск обложки и фото авторов (~10 мин — пришлось пройти через несколько источников: litres → wikipedia → erickson-foundation → ohmybrain)

## Уроки для следующих книг

1. **Для книг 1970-90-х годов обложку на litres найти сложно.** Папка `public/books/<slug>.png` — рабочее решение через локальный путь.
2. **Терапевтические книги с упоминанием суицида/абьюза/депрессии требуют safety-блок в КАЖДОМ system_prompt.** Не только в общем `programs.system_prompt` — режимы переопределяют, правила не наследуются.
3. **Имена пары авторов в БД** — можно через формат «Имя1 Фамилия1, Имя2 Фамилия2» (как в landing_data.book.author_top). Lendinга норм рендерит без правок.
4. **Прогрессия «Увидеть → Понять → Действовать»** — работает для второй терапевтической книги подряд (Берн + Гулдинги). Похоже это универсальный паттерн для терапии.

## Открытые вопросы (на будущее)

1. **Линтер не проверяет наличие safety-блока в system_prompt.** Можно добавить правило: для книг с features.test=true и шкалами про депрессию/одиночество — обязательное наличие фразы про телефон доверия.
2. **Какой формат для трёх+ авторов** (если когда-то появится). Сейчас «мы» работает для пары; для трёх — возможно нужно «команда авторов» или выбирать одного главного.
3. **Совместная история с Берном.** Сейчас в author_chat redecision-therapy упомянуто что они ученики Берна. Стоит ли добавлять явные cross-references вроде «также есть программа Берна на платформе»? Пока решил — нет, чтобы не выглядело как реклама.
